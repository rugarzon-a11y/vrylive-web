# Vrylive — sitio web (vrylive.com)

Sitio estático de Vrylive, la línea de apps psicosociales de VRYTIFY laboratoires.
Se publica en Netlify. No tiene paso de compilación.

Flujo de trabajo: cada cambio va a una rama de borrador (draft-…), Netlify genera una
vista previa, y solo cuando se aprueba ("publica") se une a `main` (producción).
